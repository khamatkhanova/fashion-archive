# архивный секонд maison margiela

## доменная область
приложение представляет собой интернет-магазин с системой пользователей,
избранного, корзины и списка задач

## сущности
user - пользователь системы

product - товар магазина

favorite - избранные товары пользователя

cartItem - товары в корзине

todo - задачи пользователя
